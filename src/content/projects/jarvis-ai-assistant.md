An ongoing personal project: an assistant that can actually reach the machine it runs on, rather
than only answering questions about it. It has been the testing ground for a lot of the
agent patterns that later showed up in client work — tool calling, deciding when to act rather
than answer, and keeping an action bounded to what was asked.
